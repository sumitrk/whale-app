# Archived project notes

These files are historical specifications, implementation logs, and exploratory designs. They are retained for context, not as current product or architecture requirements.

Current sources of truth are the checked-in `Whale.xcodeproj`, `docs/plans/`, `docs/adr/`, and the simplification tracker.

- `specifications/` contains the V0 and V1 plans and logs.
- `explorations/` contains V2 ideas and the Hopper audio-capture investigation.
